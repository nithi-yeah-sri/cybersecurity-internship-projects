# Password Strength Checker

A website that checks how strong a password is and gives specific suggestions to improve it.

## 🔒 Privacy note
Nothing typed into this tool is saved, logged, or sent anywhere.

## What this tool checks
| Check | Why it matters |
|---|---|
| Length (12+ characters) | Longer passwords are exponentially harder to crack |
| Uppercase + lowercase letters | Increases possible character combinations |
| Numbers | Same reason |
| Special characters | Same reason, blocks dictionary attacks |
| Not a commonly used password | Attackers try these first |
| No keyboard patterns | Sequences like "qwerty" are predictable |
| No repeated characters | Weaker than they look |

## How scoring works
- **0–2 points → Weak**
- **3–5 points → Medium**
- **6+ points → Strong**

## Unique feature
Instead of a random suggestion, the tool strengthens the user's own typed password by adding only what's missing (capital letter, symbol, digits) — keeping it recognizable and memorable.
