## About These Projects

- **Phishing Detection System** — Analyzes URLs and email text for common phishing indicators (fake domains, urgency language, suspicious keywords) and classifies them as Safe, Suspicious, or Likely Phishing.
- **Vulnerability Scanner** — Scans a website for missing security headers, insecure HTTP, information disclosure, and commonly-risky open ports.
- **Password Strength Checker** — Evaluates password strength (length, character variety, common patterns) and suggests a strengthened version based on the user's own input.
- **Secure Login System** — Demonstrates secure authentication using salted password hashing (PBKDF2-SHA256) and account lockout after repeated failed login attempts to prevent brute-force attacks.

Each project has its own detailed README inside its folder, explaining what it checks and why it matters.
